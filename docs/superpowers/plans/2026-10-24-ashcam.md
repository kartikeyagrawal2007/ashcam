# AshCam Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS virtual-camera app where a finger snap turns the user to ash and removes them from a live room, plus a seamless "Go away" sitting loop.

**Architecture:** One Python process. A frame loop reads the webcam, segments the person, maintains a live background plate, composites per state, and writes to the OBS Virtual Camera via pyvirtualcam. A mic listener fires snaps; a pywebview panel and global hotkeys drive the same state machine.

**Tech Stack:** Python 3.14 (Homebrew) in `.venv`, opencv-python, mediapipe (Tasks API, `selfie_segmenter.tflite`), numpy, pyvirtualcam>=0.14, sounddevice, pynput, pywebview, pytest.

**Spec:** `docs/superpowers/specs/2026-10-24-ashcam-design.md`

## Global Constraints

- Output: 1280×720 @ 30 fps RGB to device "OBS Virtual Camera".
- Everything local; the only network fetches are pip installs and the one-time MediaPipe model download into `models/`.
- No code that renames, hides or disguises the virtual camera.
- Vanish total ≈ 2.5 s (sweep 1.5 s + particle life 1.0 s); return uses the same timing reversed.
- Away clip: 3 s countdown, 15 s capture, ping-pong playback; fallback rolling buffer 5 s.
- Store buffered frames JPEG-encoded (quality 90), never raw (15 s raw 720p ≈ 1.2 GB).
- Hotkeys: ⌥⇧V vanish/return, ⌥⇧A go away. Matched by macOS virtual keycodes (V=9, A=0) plus alt+shift held, because ⌥⇧V types "◊".
- Spec deviation (UI only): panel uses pywebview (native WKWebView window, HTML/CSS) instead of tkinter, for a cleaner panel; Homebrew 3.14 has no Tk by default.

## Review Focus

1. Person never moved before snapping → plate has unseen areas → expect an inpainted fill, never a black hole. (Task 2 test `test_filled_has_no_holes`.)
2. Snap while VANISHING/RETURNING → ignored, no stuck state. (Task 1 `test_toggle_ignored_mid_transition`.)
3. Go away on while VANISHED, then off → back to VANISHED, not PRESENT. (Task 1 `test_away_restores_previous_state`.)
4. Camera returns `None` for a frame → engine re-sends last output, no crash. (Task 6 `test_dropped_frame_repeats_last`.)
5. Loud steady noise or music → no snap. (Task 4 `test_sustained_noise_no_snap`.)

## File Structure

```
ashcam/
  state.py        State enum + StateMachine (pure, timing-driven)
  background.py   BackgroundPlate
  away.py         AwayLoop + pingpong_index
  snap.py         SnapDetector (pure process() + sounddevice stream)
  dust.py         DustEffect (closed-form particles, reversible)
  segmenter.py    Segmenter (MediaPipe Tasks) + model download
  camera.py       Camera (OpenCV AVFoundation)
  engine.py       Engine: compositing + output loop thread
  hotkeys.py      Global ⌥⇧V / ⌥⇧A via pynput
  ui/panel.html   Panel markup/CSS/JS
  ui.py           pywebview window + JS API
  __main__.py     Wiring; `python -m ashcam` (`--headless` skips panel)
tests/            one test file per module
requirements.txt, README.md
```

### Task 4: Snap detector

**Files:** `ashcam/snap.py`, `tests/test_snap.py`

**Interfaces — Produces:** `SnapDetector(on_snap: Callable[[], None], sensitivity: float = 0.5, double: bool = False, samplerate: int = 48000, block: int = 512)` with `process(block: np.ndarray, now: float) -> bool` (True when it fires on_snap), `.level: float` (last score, 0..1 for the meter), `start()`, `stop()`, settable `.sensitivity`, `.double`.

Algorithm (not determined by tests): per block, high-pass at 1.5 kHz (first-order IIR or FFT band 1.5–6 kHz energy), compute RMS. Keep a slow noise floor (EMA, α=0.02, updated only when not triggered). Score = `hf_rms / (floor + 1e-4)` mapped to 0..1 via `min(1, log10(score)/2)`. Fire when score exceeds `threshold = 0.9 - 0.6*sensitivity` AND the next 2 blocks drop below 30% of the peak (transient check, so the fire is ~20 ms delayed) AND ≥0.5 s since last fire. Double mode: fire only on second qualifying transient 0.12–0.6 s after the first.

- [ ] Step 1: Tests (48 kHz, synthetic):
  - `test_snap_detected`: 1 s of noise at 0.005 then a 15 ms burst of 3 kHz-band noise at 0.5 decaying exp(−t/4ms), then silence → exactly one fire.
  - `test_sustained_noise_no_snap`: 1 s quiet (0.005) then 3 s white noise at 0.3 → no fires after t=1.2 s (the onset itself may fire at most once).
  - `test_low_thump_no_snap`: 100 Hz burst at 0.6 → zero fires.
  - `test_double_mode`: one snap → 0 fires; two snaps 0.3 s apart → 1 fire.
  - `test_refractory`: two snaps 0.2 s apart in single mode → 1 fire.
- [ ] Step 2–4: FAIL → implement → PASS (tune constants against these tests only). Commit.

### Task 5: Dust effect

**Files:** `ashcam/dust.py`, `tests/test_dust.py`

**Interfaces — Produces:** `DustEffect(snapshot: np.ndarray, mask: np.ndarray, sweep_s=1.5, life_s=1.0, seed=0)` with `.duration: float` (= sweep_s + life_s), `render(base: np.ndarray, t: float, reverse: bool = False) -> np.ndarray`, `particle_count: int`.

Model (closed form so reverse = render at `duration - t`):
- Particles: one per 3×3 block whose mask mean > 0.5; colour = block mean; origin = block centre. Cap 12 000 (random subsample).
- Release time: `r = sweep_s * clip((x - xmin)/(xmax - xmin) + noise_y(y)*0.15 + U(0,0.1), 0, 1)` (left→right, ragged edge).
- After release, age `a = t - r`; offset = `v*a + 0.5*g*a²` with `v ~ (U(60,180), U(-80,-20))` px/s and `g = (40, -60)` px/s², plus sin-noise wobble `8*sin(3a + phase)`; alpha = `clip(1 - a/life_s, 0, 1)`; size 2 px → 1 px as alpha falls.
- Unreleased body: draw `snapshot` where mask>0.5 and `r > t` (per-pixel release map at full res, from the same formula), with a 1 px warm glow (`+30` on R) on pixels within 0.05 s of release.
- Draw particles with alpha blending onto `base` (vectorised `np.add.at` into an accumulation buffer, then blend).

- [ ] Step 1: Tests (64×64 synthetic: base all 0, person square of 255 in centre):
  - `test_start_is_person`: `render(base, 0)` centre pixel ≈255.
  - `test_end_is_base`: `render(base, duration+0.01)` == base exactly.
  - `test_reverse_is_mirror`: `render(base, t, reverse=True)` == `render(base, duration - t)` for t in {0.3, 1.2, 2.0}.
  - `test_left_goes_first`: at t=0.6 the left third of the square has more base pixels than the right third.
- [ ] Step 2–4: FAIL → implement → PASS. Commit.

### Task 6: Camera, segmenter, engine

**Files:** `ashcam/camera.py`, `ashcam/segmenter.py`, `ashcam/engine.py`, `tests/test_engine.py`

**Interfaces:**
- Consumes: Tasks 1–5 as defined.
- Produces:
  - `Camera(index=0, width=1280, height=720, fps=30)`: `read() -> np.ndarray | None` (BGR), `close()`. Uses `cv2.CAP_AVFOUNDATION`; device chosen by the `--camera N` flag, default 0 (built-in camera).
  - `Segmenter(model_path="models/selfie_segmenter.tflite")`: `mask(frame_bgr) -> np.ndarray float32 HxW 0..1`. Downloads model from `https://storage.googleapis.com/mediapipe-models/image_segmenter/selfie_segmenter/float16/latest/selfie_segmenter.tflite` if missing. VIDEO running mode with monotonically increasing ms timestamps. Output mask smoothed: `GaussianBlur(7×7)` and EMA α=0.6 against the previous mask.
  - `Engine(camera, segmenter, away: AwayLoop, sm: StateMachine, sink: Callable[[np.ndarray], None] | None = None)`: `process(frame: np.ndarray | None, now: float) -> np.ndarray` (BGR out), `toggle_vanish()`, `toggle_away()`, `.latest: np.ndarray | None`, `.status() -> dict` (`state`, `away`, `away_rec`, `snap_level`, `vcam_ok`, `error`), `start()` / `stop()` (background thread: read → process → send to `pyvirtualcam.Camera(1280,720,30, fmt=RGB, backend="obs")` with `sleep_until_next_frame`).

Compositing per spec §Compositing. On entering VANISHING: `DustEffect(frame, mask)`, base for each tick = `composite(frame, filled_plate, mask_at_trigger dilated)`. VANISHED: feathered mask (dilate 9 px, blur 21 px). On entering RETURNING: `DustEffect(current frame, current mask)` rendered with `reverse=True` over the vanished composite; after it ends, 0.2 s cross-fade into raw. Plate updates every frame in every state except AWAY.

- [ ] Step 1: Tests with a `FakeSegmenter` (returns a fixed centre-square mask) and synthetic frames:
  - `test_present_passthrough`: PRESENT → output == input.
  - `test_vanished_shows_plate`: feed 5 frames with bg value 80 while "person" (value 250) is in centre, toggle, process until VANISHED → centre ≈80 (±5).
  - `test_live_background_when_vanished`: in VANISHED, feed frame with bg 140 → output corners ≈140.
  - `test_away_plays_clip`: push frames into AwayLoop, toggle_away → output equals a clip frame (±3).
  - `test_dropped_frame_repeats_last`: `process(None, now)` after a real frame → returns previous output, no exception.
- [ ] Step 2–4: FAIL → implement → PASS.
